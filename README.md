# 🌱 ชื้นอ๊ะยังจ๊ะ (Eart Plus)

ระบบรดน้ำต้นไม้อัตโนมัติด้วย **ESP32** สำหรับตรวจวัดความชื้นในดิน ควบคุมปั๊มน้ำอัตโนมัติ และสามารถตรวจสอบและควบคุมระบบผ่านโทรศัพท์มือถือแบบ Real-time

## 📌 รายละเอียดโครงงาน

**ชื้นอ๊ะยังจ๊ะ (Eart Plus)** เป็นระบบรดน้ำต้นไม้อัตโนมัติที่พัฒนาด้วย **ESP32** โดยระบบจะตรวจวัดค่าความชื้นในดินและนำค่าที่ได้มาใช้ในการควบคุมปั๊มน้ำ

ระบบสามารถทำงานได้ทั้งแบบ **อัตโนมัติ (Auto Mode)** และ **ควบคุมด้วยตนเอง (Manual Mode)** ผ่านสวิตช์ที่ติดตั้งบนอุปกรณ์ รวมถึงสามารถเชื่อมต่อกับโทรศัพท์มือถือผ่าน Wi-Fi เพื่อดูค่าความชื้นในดินและอุณหภูมิอากาศแบบ Real-time และสามารถสั่งเปิด-ปิดปั๊มน้ำจากโทรศัพท์ได้

---

## 🎯 วัตถุประสงค์

- ตรวจวัดค่าความชื้นในดิน
- ตรวจวัดอุณหภูมิของอากาศ
- ควบคุมการรดน้ำต้นไม้อัตโนมัติ
- แสดงค่าความชื้นและอุณหภูมิผ่านจอ OLED
- สามารถควบคุมระบบผ่านสวิตช์
- สามารถดูข้อมูลผ่านโทรศัพท์มือถือ
- สามารถสั่งเปิดและหยุดปั๊มน้ำผ่านโทรศัพท์
- ลดปัญหาการรดน้ำมากหรือน้อยเกินไป

## ⚙️ หลักการทำงาน

ระบบจะอ่านค่าความชื้นจาก **Soil Moisture Sensor** แล้วนำค่าที่ได้มาเปรียบเทียบกับค่าที่กำหนดไว้

| ความชื้นในดิน | สถานะดิน | การทำงาน |
|---|---|---|
| `≤ 35%` | 🌵 ดินแห้ง | เปิดปั๊มน้ำ |
| `36% - 59%` | 💧 อยู่ระหว่างช่วงกำหนด | ปิดปั๊ม |
| `≥ 60%` | 🌱 ดินชื้น | ปิดปั๊มน้ำ |

### การทำงานแบบ Auto

```text
เริ่มต้น
   │
   ▼
อ่านค่าความชื้นในดิน
   │
   ▼
ความชื้น ≤ 35% ?
   │
   ├── ใช่ ──► เปิดปั๊มน้ำ
   │
   └── ไม่ใช่
          │
          ▼
   ความชื้น > 35% ?
      │
      └── ใช่ ──► ปิดปั๊มน้ำ
```

เมื่ออ่านค่าความชื้นไม่ได้ ระบบจะปิดปั๊มเพื่อความปลอดภัย

---

## 🎛️ การทำงานของสวิตช์

ระบบมีสวิตช์ทั้งหมด 3 ตัว

### 🔘 Switch 2 — Manual Pump Toggle

ใช้สลับสถานะปั๊มได้เมื่ออยู่ใน Manual Mode

```text
Manual + กด Switch 2 → สลับ Pump ON/OFF
Auto + กด Switch 2 → ไม่เปลี่ยนสถานะปั๊ม
```

---

### 🔘 Switch 3 — Manual Mode

เมื่อกด Switch 3 ระบบจะเข้าสู่โหมด Manual

```text
กด Switch 3 → Manual Mode
```

---

### 🔘 Switch 1 — Auto Mode

เมื่อกด Switch 1 ระบบจะเข้าสู่โหมดอัตโนมัติ โดย ESP32 ควบคุมปั๊มตามค่าความชื้น

```text
Soil ≤ 35% → Pump ON
Soil 36-59% → Pump OFF
Soil ≥ 60% → Pump OFF
```

## 📱 การเชื่อมต่อโทรศัพท์

ESP32 สามารถเชื่อมต่อกับ Wi-Fi และเปิดหน้าเว็บไซต์สำหรับตรวจสอบและควบคุมระบบ

ผู้ใช้งานสามารถเปิดเว็บไซต์จากโทรศัพท์ที่เชื่อมต่อ Wi-Fi เดียวกับ ESP32

หน้าเว็บไซต์สามารถแสดงข้อมูลแบบ Real-time ได้แก่

- 🌡️ อุณหภูมิอากาศ
- 🌱 ความชื้นในดิน
- 💧 สถานะปั๊มน้ำ
- ⚙️ สถานะ Auto / Manual

---

## 📲 การควบคุมผ่านโทรศัพท์

ผู้ใช้งานสามารถควบคุมระบบผ่านหน้าเว็บไซต์ได้

### Auto Mode

เลือก Auto Mode ระบบจะควบคุมปั๊มตามค่าความชื้น

```text
ESP32 ตรวจสอบความชื้น
   ↓
≤ 35% → Pump ON
≥ 60% → Pump OFF
```

### Manual Mode

เลือก Manual Mode เพื่อควบคุมปั๊มเอง

### Pump ON

สั่งเปิดปั๊มได้เฉพาะ Manual Mode

### Pump OFF

สั่งหยุดปั๊มได้เฉพาะ Manual Mode

---

## 🖥️ การแสดงผลบน OLED

ระบบใช้จอ OLED ขนาด **0.96 นิ้ว I2C** เพื่อแสดงข้อมูลปัจจุบัน

ตัวอย่างการแสดงผล

```text
T:25.0C Mode:Auto
Soil:34% Pump:Auto
```

เมื่ออยู่ใน Manual ค่า Pump จะแสดง `ON` หรือ `OFF` ตามสถานะปั๊ม

ความหมาย:

- `T` = อุณหภูมิอากาศ
- `Soil` = ความชื้นในดิน
- `P:ON` = ปั๊มน้ำทำงาน
- `P:OFF` = ปั๊มน้ำหยุด
- `Auto` = โหมดอัตโนมัติ
- `Man` = โหมด Manual

## 🔌 อุปกรณ์ที่ใช้

| อุปกรณ์ | หน้าที่ |
|---|---|
| ESP32 | ควบคุมระบบทั้งหมด |
| Soil Moisture Sensor | วัดความชื้นในดิน |
| DHT22 | วัดอุณหภูมิอากาศ |
| IRLZ44N MOSFET | ควบคุมปั๊มน้ำ |
| Water Pump | รดน้ำต้นไม้ |
| OLED 0.96 นิ้ว I2C | แสดงข้อมูล |
| Switch 1 | เลือก Auto Mode |
| Switch 2 | สลับปั๊มใน Manual Mode |
| Switch 3 | เลือก Manual Mode |
| Wi-Fi | เชื่อมต่อโทรศัพท์กับ ESP32 |

---

## 🔧 การกำหนด GPIO

| อุปกรณ์ | ESP32 GPIO |
|---|---:|
| Soil Moisture Sensor | GPIO 32 |
| DHT22 | GPIO 4 |
| MOSFET Gate / Pump | GPIO 27 |
| Switch 1 | GPIO 13 |
| Switch 2 | GPIO 14 |
| Switch 3 | GPIO 25 |
| OLED SDA | GPIO 21 |
| OLED SCL | GPIO 22 |

> **หมายเหตุ:** GPIO27 ควบคุม Gate ของ IRLZ44N โดยตรง ให้ตรวจสอบว่า Gate ต่อถูกขาและใช้แหล่งจ่ายแยกที่เหมาะกับปั๊ม ห้ามจ่ายไฟปั๊มจาก GPIO หรือขา 3.3V ของ ESP32

## 🌐 การสื่อสารแบบ Real-time

ระบบใช้ **WebSocket** สำหรับส่งข้อมูลระหว่าง ESP32 และโทรศัพท์

ตัวอย่างข้อมูลที่ส่ง:

```json
{
  "temp": 28.5,
  "soil": 32,
  "pump": 1,
  "auto": 1
}
```

ความหมายของข้อมูล:

| ตัวแปร | ความหมาย |
|---|---|
| `temp` | อุณหภูมิอากาศ |
| `soil` | ความชื้นในดิน |
| `pump` | สถานะปั๊มน้ำ |
| `auto` | สถานะ Auto Mode |
